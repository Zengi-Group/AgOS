# AGOS — Правила дизайна фермерской зоны (канон)

**Status:** Adopted 2026-07-10 (DECISIONS_LOG → D-UI-FARMER-RULES-01).
**Scope:** вся фермерская зона — кабинет `/cabinet` (`.agos-cabinet-stage`, включая MPK-шелл, который наследует `cabinet.css`) + вход-фаннел (`/welcome`, `/login`, `/register`, `/membership`, светлая «paper», `src/lib/auth-ui/tokens.ts`).
**НЕ распространяется на:** админку/экспертку (`[data-shell]` — канон `AGOS-DesignSystem-v12.md`) и публичный лендинг (`:root`, легаси-палитра).

> Этот файл — единственное место, где живут визуальные правила фермерской зоны.
> Правки дизайна от CEO анализируются и фиксируются здесь как правила (§ Реестр правил из правок CEO) — чтобы одна и та же правка не повторялась дважды.

## 1. Палитра

- Кабинет = **только светлая тема «daylight»** (решение CEO 2026-07-09): `--bg #f6f3ed`, `--bg-c #fbfaf6`, `--fg #3d2b1f`, акцент `--accent #E8920B`. Тёмная «night» + переключатель — отложены (значения есть в DS прототипа).
- Цвета — **только через токены** `.agos-cabinet-stage` (`--bg/--fg/--bd/--accent/--cta/…` + muted-подложки `--*-m`). Литеральный hex в компонентах — дефект.
- CTA-кнопка тёмная (`--cta #3d2b1f`), акцент-амбер — для активных состояний, Turan-star и амбер-актива таб-бара.
- Boot-фон: `--boot-bg #fdf6ee` (BootScreen, инлайн-плейсхолдер `#root`) — никаких белых провалов на пути в кабинет.

## 2. Типографика

- Шрифт: **Geist** (UI), **Geist Mono** (цифры/ID) — через `var(--font-sans)`/`var(--font-mono)`.
- **Mono только для данных** (R-9): `mk-mono` (Geist Mono) — исключительно цифры, цены, счётчики, ID, даты. Любая текстовая микрокопия на русском (подписи под CTA, подписи категорий/вариантов, eyebrow-строки, hints) — Geist sans. `mk-mono` на фразе = дефект. Смешанная строка («защитная: 1 400 ₸/кг») — фраза в sans, числовая часть при необходимости в mono-`span`.
- Гоча Ionic: внутри `ion-content` шрифт берётся из `--ion-font-family` (задан Geist в `ionic.css`), кнопки/инпуты требуют `font-family: inherit` — уже задано на `.agos-cabinet-stage`; не ломать.
- Никаких новых шрифтовых семейств без решения CEO (бюджет загрузки шрифтов — 7 семейств, ARS-217).

## 3. Иконки (правило Phosphor-only)

- **Только Phosphor Icons** — через единый `PhIcon` (пути 1:1 из прототипа) или `@phosphor-icons/react`. Логотип — отдельный `TuranStar`.
- **Никогда:** lucide в фермерской зоне, самодельные SVG-пути, эмодзи вместо иконок (📞⏰ → PhIcon `phone`/`clock` — уже исправлялось), стикеры в хедере.
- **Вес = вес блока:** сервис-плитки Главной = **bold**, in-content = regular, membership-флоу = duotone; тонкие (`userThin`) — аватар/аккаунт.
- Новая иконка = добавить путь в `PhIcon.tsx`, не импортировать вторую библиотеку.

## 4. Язык стиля (усвоено из правок CEO)

- **Плоскость, не украшательство:** карточки плоские, радиус 12 (`--r-xl`, как `obs-card`/`dec-row`), без теней-подложек у внутренних блоков («РЕКОМЕНДУЕМ» — плоский), иконки без плиток-подложек.
- **Один акцент на блок**, подпись только у активного элемента (паттерн HomeStartLadder).
- Пустые состояния — мягкий органичный «блоб» (`color-mix accent 10%`), не квадратная рамка; заголовок 19px/700 (UI-EMPTYSTATE-01).
- CTA-тексты короткие («Снизить цену», «Варианты» — не предложения).
- **Карточка данных = внутренняя сетка** (R-15): шапка «заголовок+контекст слева | семантический чип справа» → главное число с тренд-барами по базовой линии → тихий подвал-пояснение. Один цветовой акцент на карточку — чип с тонированной подложкой (`color-mix` ok/warn 12–14%). Термин, которого фермер может не знать («защитная цена»), сопровождается иконкой-пояснением (PhIcon regular, fg3). Элементы, «висящие в воздухе» без выравнивания к сетке, — признак генеративного дизайна, дефект.
- **Вторичное действие — под primary CTA в доке** (R-13), не между полем ввода и CTA: паттерн MkCta + тихая ссылка (как «Пропустить вопрос» в мастерах) действует и в auth-фаннеле.
- **Один путь вперёд на экранах флоу** (R-14): шаг/награда мастера держит primary CTA + один выход; дополнительные навигационные ссылки в теле («Все цены TURAN ›») убираются — справочники доступны из постоянной навигации.
- Отвергнутые направления (не предлагать заново): full-screen takeover-экраны для онбординг-подсказок («новый экран»), карты с номерами шагов + прогресс-баром («перегруз»), голые hairline-списки («утилитарно, не стильно»).

## 5. Структура и навигация

- **Портируем структуру прототипа** (разметка + CSS + иконки), не ре-темизируем старый код. Переиспользуем атомы `.mk-*`/`.sh-*`/`PhIcon`; RPC/данные/навигация — инварианты.
- Хедеры, 3 уровня: `HomeHead` (ask-бар — только Главная) · `TabHead` (вкладки) · `SubHead` (`‹ back-label`, sticky, сплошной фон).
- Таб-бар: 4 таба (Главная/Ферма/Рынок/Сообщения), амбер-актив; **скрыт на детальных экранах** (`hideTabBar`, route-based) — фуллскрин-UX деталей сохраняем (решение CEO, ARS-220).
- Страницы непрозрачны (`ion-content --background: var(--bg)`) — bleed-through при слайде недопустим; `backdrop-filter: blur` в хедерах не использовать.
- Переходы нативные iOS (`mode:'ios'`, swipe-back); модальные флоу — slide-up `.agos-flow-page`.
- Дисклеймер ст.171 — всюду, где показаны референс-цены (`.mk-ref-d`).

## 6. Запрещено в фермерской зоне

- Тёмная тема / переключатель тем (до отдельного решения)
- lucide-react, самодельные SVG-иконки, эмодзи в UI-копирайте
- Литеральные hex вместо токенов
- Тени/подложки у внутренних блоков карточек, плитки под иконками
- Стикеры/иллюстрации в хедерах
- `backdrop-filter: blur`, прозрачные `ion-page`
- Удаление функционала ради «упрощения UX» (HS-2)
