# ARS-786 · Входящие офферы в консоли МПК — ответить

<frozen-after-approval>

## Замысел

Снабженец видит живые офферы (`ARS-785`), но заключить сделку не может: ходов нет.
Слайс даёт два — принять и отклонить — и делает исход понятным: куда ушла партия, по
какой цене, а при отказе почему. Последнее недостающее действие комбината на пилотной
десктопной поверхности.

## Границы

**Always**
- Заявка-получатель называется **после** принятия, из ответа RPC: выбор делает база
  (`order by pl.mpk_price_per_kg desc limit 1`), экран его не предсказывает.
- Цена сделки — `dealPrice` из ответа: бид комбината, не ask фермера (`D-M6-DEALPRICE`).
- Отказ — человеческой фразой; нераспознанный код даёт общую фразу + код мелким.
- После любого хода список перечитывается: отвеченный оффер уходит.
- Личность фермера не раскрыта до подтверждения сделки (`D-M6-12`). Ст. 171: без побуждения.

**Never**
- Выбор заявки оператором — нужна правка сигнатуры `rpc_self_accept_offer`; слайс UI-only.
- Общий словарь отказов (`ARS-691`) и правка мобильного шелла — вне слайса.

## Spec Change Log  (append-only)

### [2026-09-24] Допущение о временной карте отказов СНЯТО своим же условием

**Находка-триггер:** `ARS-691` («Отказы базы в зоне МПК — фразой из словаря») выложен на
прод (PR #220 · #221) в то время, пока этот слайс стоял на якоре 7. Спек назвал ровно это
опровержением своего допущения: «**Опровергло бы:** `ARS-691` выходит раньше сборки — тогда
раздел берёт общий словарь, а карта удаляется, а не остаётся вторым домом (`P4`)».

**Что правлено:** только КОД, не замороженный блок. Локальная карта на семь кодов удалена
целиком; `explainOfferFailure` стал тонкой обёрткой над `rpcErrorText`
(`data/rpc-error-text.ts`), который покрывает все семь кодов экрана плюс сеть той же
логикой «код до первого двоеточия». Проверка формы ответа теперь бросает `LocalError` —
собственный текст фронта, который словарь пропускает мимо таблицы кодов.

**Приёмку правка не двигает:** строка «семь кодов → фраза без кода в теле; неизвестный →
общая фраза + код мелким» проверяется тем же тестом и проходит без изменений — фразы
совпали посимвольно, потому что временная карта и была скопирована из подписанной таблицы D.

**propagated:** `data/offer-actions.ts` (карта удалена) · `MpkOffersApp.tsx` (ошибка
отдаётся словарю целиком) · `IMPL_DEBT.md` (`MPK-OFFERS-ERRORS-PARTIAL-DICT-01` закрыт, а
не отложен). **Переподпись не требуется:** frozen-блок не тронут, снятие допущения
предусмотрено самим спеком.
