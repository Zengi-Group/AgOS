# ARS-785 · Входящие офферы в консоли МПК — увидеть

<frozen-after-approval>

## Замысел

Партии без прямого матча приходят снабженцу офферами и висят 24 часа, но раздела для
них в веб-консоли нет — они тихо истекают, и оператор решает, что рынок пуст. Слайс
даёт третий построенный раздел консоли: список живых офферов со сроком ответа.
Отвечать на них — `ARS-786`.

## Границы

**Always**
- Новый маршрут `/mpk/offers` в существующей консоли; живые URL не переименованы (P7).
- `offers` входит в `BUILT_SECTIONS`. Гейт Slice 10 распечатывается **новым `FR-021`**
  (§13.2) по образцу `FR-020`: `FR-013` не переписывается, `FR-018`/`FR-019` не трогаются
  (резерв ARS-627). Slice 10 требует новой подписи владельца.
- Чтение различает `ok` / `no_session` / `failed` с проверкой `getSession().error` (образец
  `readMyPools`). Демо-офферы реальному оператору не показываются никогда (п.4 `ARS-688`).
- Личность фермера не раскрыта (`D-M6-12`). Ст. 171: только факты, без побуждения.
  Зона `[data-shell]` — дизайн-система `v12`.

**Never**
- Принять/отклонить — `ARS-786` (кнопок здесь нет).
- Маркет-борд, «Документы сделок», история отвеченных — вне слайса (владелец 22.09).
- Мобильный шелл не правится (довод `FR-014` Слайса 11).
