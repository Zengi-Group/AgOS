## 3. Полное описание

### RU
**AgOS · TURAN — рабочий кабинет фермера ассоциации TURAN.**

Инструмент для ежедневного управления хозяйством, а не витрина. Всё в одном приложении:

• **Стадо** — учёт поголовья по группам, отметки обхода, состояние животных.
• **План работ** — задачи по циклу (случка, отёл, вакцинация, взвешивание) на неделю, месяц и год; норма против факта.
• **Рынок (TSP)** — координация сбыта скота между фермерами и переработчиками ассоциации. Индикативные ценовые ориентиры, добровольное участие.
• **Членство** — заявка и статус в ассоциации TURAN.
• **Работает офлайн** — данные доступны без связи, действия синхронизируются при возврате сети.
• **Уведомления** — напоминания о задачах и событиях хозяйства.

_TURAN — отраслевая ассоциация животноводов Казахстана. Рынок (TSP) — инфраструктура координации, а не торговая площадка: цены носят индикативный характер (ст. 171 Предпринимательского кодекса РК). Участие добровольное._

Приложение предназначено для членов и партнёров ассоциации TURAN.

### KK 🚩 (вычитать)
**AgOS · TURAN — TURAN қауымдастығы фермерінің жұмыс кабинеті.**

Шаруашылықты күнделікті басқаруға арналған құрал. Барлығы бір қосымшада:

• **Мал басы** — топтар бойынша есеп, аралау белгілері, малдың жағдайы.
• **Жұмыс жоспары** — цикл бойынша тапсырмалар (шағылыстыру, төлдеу, вакцинация, өлшеу) аптаға, айға, жылға; норма мен нақты көрсеткіш.
• **Нарық (TSP)** — қауымдастық фермерлері мен өңдеушілері арасында мал өткізуді үйлестіру. Бағалар — бағдарлық, қатысу — ерікті.
• **Мүшелік** — TURAN қауымдастығына өтініш пен мәртебе.
• **Желісіз жұмыс істейді** — деректер байланыссыз қолжетімді, әрекеттер желі оралғанда синхрондалады.
• **Хабарламалар** — тапсырмалар мен оқиғалар туралы еске салу.

_TURAN — Қазақстанның мал шаруашылығы саласының қауымдастығы. Нарық (TSP) — сауда алаңы емес, үйлестіру инфрақұрылымы: бағалар бағдарлық сипатта (ҚР Кәсіпкерлік кодексінің 171-бабы). Қатысу ерікті._
